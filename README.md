# 🍽️ Super-Meme – Site Vitrine Bilingue (FR/EN)

## 📌 Description
Ce projet est un **site vitrine bilingue (Français/Anglais)** pour un restaurant moderne.  
Il est conçu pour être **responsive**, optimisé pour le **SEO**, et prêt à être déployé sur **GitHub Pages**.

---

## ✨ Fonctionnalités
- 🌐 **Bilingue (FR ↔ EN)** avec switch de langue
- 📱 **Responsive design** (PC, tablette, mobile)
- 🖼️ Galerie d’images pour menus et boissons
- 📍 Section localisation avec carte
- 📞 Formulaire de contact simple
- 🔍 **SEO optimisé** (balises meta, sitemap, robots.txt)
- 📊 **Google Analytics** intégré pour suivi des visiteurs
- 🎨 **Menu burger mobile** pour navigation fluide

## 📈 SEO & Optimisation
- Balises `<meta>` pour description, mots-clés, auteur.  
- Open Graph + Twitter Cards pour partage sur réseaux sociaux.  
- `sitemap.xml` et `robots.txt` pour indexation optimale.  
- Images compressées (<1 MB) et renommées (`menu1.jpg`, `jus.jpg`, `logo.png`).  
- Media queries pour un rendu fluide sur mobile/tablette.  
- Favicon pour identité visuelle.  

---

## 📊 Google Analytics
- Ajoute ton **Measurement ID** (ex. `G-XXXXXXXXXX`) dans `index.html`.  
- Vérifie le suivi des visiteurs après déploiement via ton tableau de bord Analytics.
